
# Shahzada Mustafayev

Industrial Engineering undergraduate at Azerbaijan State Oil and Industry University (ASOIU), with research interests in **Reliable AI, Multilingual NLP, and Machine Learning Evaluation**.

My work focuses on understanding how machine learning systems perform, where they fail, and how their reliability can be evaluated.

## Selected Research

### [Knowing When Not to Answer](https://github.com/mstfyvshzde/Knowing-When-Not-to-Answer)

Research on selective question answering, confidence calibration, and NLI-based verification.

- **Dataset:** SQuAD v2, 3,000 held-out examples
- **Methods:** Risk–coverage analysis, AURC, paired bootstrap
- **Finding:** Calibrated confidence achieved the lowest AURC (0.2924), outperforming the evaluated verification combinations.
- **Output:** Open-access technical report archived on Zenodo.

### [Adaptive AI Tutor Research Lab](https://github.com/mstfyvshzde/adaptive-ai-tutor-research-lab)

Applied machine learning research using student interaction data.

- **Dataset:** EdNet KT1, 500,057 interactions
- **Methods:** Supervised learning, feature engineering, ablation studies
- **Result:** ROC-AUC of 0.7301 using Gradient Boosting
